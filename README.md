# مُخطّطي
مخطط يومي بالعربي: مهام بمواعيد وتنبيهات، مواقيت الصلاة + أذان + حوار "والله صليت", ميزانية الشهر, مناسبات, وتقرير آخر اليوم.
تخزين: **على الجهاز** أو **جوجل + Supabase**. فرونت إند ثابت (ES modules) من غير build. التفاصيل في `SETUP.md`.
الأذان: `assets/adhan.mp3` (ممكن تستبدله من المزيد). مواقيت الصلاة: adhan-js (الهيئة المصرية). Fonts: Readex Pro, Aref Ruqaa (OFL).
